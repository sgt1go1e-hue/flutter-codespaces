# 配管アイソメ図作成アプリ (PWA)

スマホのブラウザで動作する、配管アイソメ図を手書き入力するための PWA。
React + TypeScript + Vite + SVG で実装。

## 開発

```bash
cd app
npm install
npm run dev      # 開発サーバー (http://localhost:3000)
npm run build    # 型チェック + 本番ビルド
npm run preview  # ビルド結果のプレビュー
```

## 技術選定メモ

- **描画は SVG を採用**（Canvas ではなく）。
  各セグメントを DOM 要素として持てるため、タップ選択・ハイライト・
  属性の紐付けが素直に書ける。フェーズ2以降の「セグメント選択→属性設定」
  との相性が良い。

## 追加仕様（フェーズ2後の改善）

- **グリッド交点拘束描画**: 線は必ずアイソメ格子の交点から交点へ、アイソメ角に沿って確定する
  （`snapSegmentToGrid` / `snapToLattice`）。中途半端な位置・角度では確定しない。
  分岐（チーズ）の起点も常に交点に乗るため接続が崩れない。
- **属性の継承**: 各セグメントは親（上流）セグメント ID (`parentId`) を持ち、
  管種・サイズが未設定なら親をたどって継承する（`lib/inheritance.ts`）。
  レジューサー等でサイズを明示変更すると、その下流も新サイズを継承する。
  継承中のサイズはラベルに `*` を付け、控えめ色で表示。
- **描画優先**: 属性を選ばなくても線は常に引ける。未設定セグメントは継承値を仮適用し、
  実効サイズが未確定なものは破線グレーで「未確定」と分かる表示にする。
- **引き始めの誤爆防止**: タッチ直後 `ARM_DELAY`(≈180ms) は長押し判定を開始せず、
  この間に動けば描画になる。静止し続けた場合のみ `LONG_PRESS_HOLD`(≈350ms) を経て選択
  （合計 ≈530ms）。描画中・選択操作自体の感度は据え置き。
- **またぎ表示**: データ上つながっていない線が視覚的に交差する箇所で、
  後から描いた線を小さく途切れさせる（`lib/crossover.ts`）。見た目のみで接続関係には影響しない。
- **パーツパレット**（`data/parts.ts` / `components/PartsPalette.tsx`）:
  画面下部のチップを配管上へドラッグ&ドロップして特殊部材を配置。
  `partsPalette` 配列に定義を足せば、同じ仕組みでバルブ・ストレーナー等を追加できる汎用構造。
- **フランジ（両 / 片）**:
  - **両フランジ**: 配置点で対象セグメントを前後2本の独立データに分割
    （A=上流は属性保持、B=下流は A を親に継承）。接合ノードの両側にフランジ面が付く。
    分割後は前後それぞれ独立して選択・削除・属性変更できる。
  - **片フランジ**: 分割せず、近い側の端を終端エンドとしてマーク。
  - 記号: 両フランジは接続点を挟んで前後に1本ずつ＝**2本のペア**、片フランジは1本（表示のみ）。
  - 種別はパレット定義（`FlangeType`）が保持し、配置後も属性ポップアップの
    「フランジ（始点側/終点側）」で なし / 両 / 片 を変更可能（属性入力では分割はしない）。
- **サイズ表示の間引き**: サイズが切り替わった地点（実効サイズが上流と異なるセグメント）
  のみにサイズを1箇所表示。同一サイズが継承され続ける後続には表示しない。
  ※表示のみの制御で、データは全セグメントがサイズ値を保持（集計計算には影響しない）。

## UI簡略化（入力の手間を最小化）

現場の手書き感覚に近づけるための省タップ設計。

- **常設属性パネル**（`components/AttributePanel.tsx`）: ポップアップ／アクションメニューを廃止。
  描画エリア下部に常設し、選択中セグメントの 管種 / サイズ / 継手 / 接続方法 / 芯々寸法 を
  その場で編集。現在値をヘッダに常時サマリ表示。折りたたみで描画スペースを確保。
  **線をタップ＝選択**（長押し不要）、空白タップで選択解除、削除はパネルのボタン。
- **寸法連続入力の高速化**: 寸法（セグメント）編集パネルと「作図設定」バーを完全分離。
  作図設定は独立した折りたたみバーで、選択・寸法入力では自動展開しない（割り込まない）。
  線をタップで選択すると **芯々寸法欄へ自動フォーカス**するので、
  「線タップ→入力→次の線タップ→入力」を1本1タップで連続できる。
- **作図設定（選択不要の入力）**: 線を選択していないとき、パネルは「作図設定」モードになり、
  これから描く線に適用する 管種 / サイズ / 接続方法 をその場で設定できる（`piping-iso:defaults` に保存）。
  - 管種・サイズはルート（接続元なし）の線に付与→続きの線は上流から継承（レジューサー伝播は維持）。
  - 接続方法は新規線すべてに適用。設定を変えて別ルートを描けば、その値で作図される。
  - 個別に直したい線だけ長押しで選択して上書き。
- **継手は1項目に統合**: `startFitting`/`endFitting` を廃し `fitting` 1つに。切断計算は両端に同じ継手を適用。
- **継手デフォルト自動**: 未指定なら、分岐（次数3以上のノードに接する区間）は `tee`、
  それ以外は `elbow90` を実効値に（`inheritance.ts`）。明示選択で上書き可。
- **分岐の接続を確実化**: 描画開始点が既存線の近くなら、その線上の格子点へ吸着（グリッド拘束は維持）。
  これにより中間分岐（チーズ）が確実に接続し、tee 自動判定も効く。

## 免責事項の同意

- 初回起動時に**免責事項モーダル**を全画面ブロッキング表示。「同意する」を押すまで描画等の操作は不可。
- 同意すると `piping-iso:consent` に **版(version)＋同意日時(agreedAt)** を保存し、以後は再表示しない。
- トップバーの「免責」ボタンからいつでも**再確認**（閉じるだけ・同意日時も表示）。
- 文面を改定して再同意を求めたい場合は `App.tsx` の `CONSENT_VERSION` を上げると、
  旧版で同意済みの端末に再度モーダルが出る。

## フェーズ3: 切断（加工）寸法の自動計算

アイソメ図は非スケールのため、線のピクセル長ではなく **区間ごとの芯々寸法(mm)を手入力**する方式。

- 属性ポップアップに「芯々寸法(mm)」入力欄と、計算内訳（芯々 − 始点側 − 終点側 = 切断長）を表示
- 計算式: `切断長 = 芯々寸法 − 始点側の取り出し寸法 − 終点側の取り出し寸法`
  - **端ごと（per-end）にノードの役割から算出**（`lib/takeout.ts`）。各端が接続するノードを
    幾何学的に判定し、役割（エルボ / チーズ・ラン / チーズ・枝 / レジューサー / 直管 / フリー端）と
    **そのセグメント自身の実効サイズ**で `fittings.json` を引く。
  - チーズはラン(C)・枝(M)を出し分け。レジューサーは大径側=0/小径側=全長H。
  - **サイズ継承がレジューサーを跨いで縮小**（`effectiveSize` がレジューサー継手で小径を下流へ）。
    100A→65A の下流は 65A の引きしろで計算される。
  - フリー端（未接続の端）は差し引かず「芯出し基準」。
  - 再計算は segments 変更のたび（描画・削除・属性変更・分岐追加）に自動実行。
- **寸法の2段表記**（手書きアイソメ流）: 各区間に上段＝芯々寸法（控えめ色）、
  下段＝切り寸法（緑・下線で強調＝現場で使う数値）を上下に表示。
- **芯々 / 芯先の区別**: 両端継手接続＝「芯々」、片端フリー＝「芯先」を寸法脇に表示。
- **パイプ0mm / 継手不足**: 切り寸が0付近なら「パイプ0（継手直結）」、負なら赤字
  「継手が収まりません（芯々不足）」を表示（負値は出さず0にクランプ）。
  切り寸 ≤ 0 の区間は `countable=false` とし、BOM のパイプ材から除外できる。
- 属性パネルに端ごとの役割・差引、芯々/芯先、0mm・継手不足の注記を表示。
- **レジューサーの途中挿入**: パーツパレットの同心/偏心レジューサーを配管上の任意点へ
  ドロップすると、その位置で前後に分割し下流を1段小径にする（交点以外にも配置可）。

## フェーズ1でできること

- 背景に **アイソメ（等角投影）グリッド**（30°/150° の菱形パターン）を常時表示し、描画のガイドにする
- 指でドラッグしてフリーハンド描画
- 離すと最寄りのアイソメ角度（0° / 30° / 90° / 150° / 210° / 270° / 330°）へ自動スナップ
- 線の始点・終点は近くの既存端点へ吸着し、ルートを連結できる
- **ロングタップ（約500ms 長押し）で線を選択**し、近くにアクションメニュー（「寸法・属性を入力」「削除」）を表示
  - 指を置いてすぐ動かせば描画、動かさず止めれば選択、と判定を分離（連続描画・分岐と競合しない）
  - メニュー外タップで選択解除
- 「元に戻す」「全消去」
- 図面（セグメント配列）は localStorage に自動保存

### 継手マスタ（実データ）と計算方式

`fittings.json` はイノック（SUS304 突合せ溶接式）の公開寸法表を基にした実データ。
呼び径・OD が同じなら SGP/STPG 等でも同値として扱う（`source: "inoc_SUS304_buttweld"` で出典管理）。

継手ごとに計算方式（`calc`）が異なり、`cutlength.ts` で分岐：
- **centerMinus**（90°/45°エルボ・チーズ）: 中心〜端面寸法を両端から差し引く
- **overall**（レジューサー）: 継手全長 H を差し引く。大径_小径キーのため「相手径」の指定が必要
- **endDepth**（キャップ）: 終端の深さを片側で差し引く

サイズキー: 単一継手=呼び径A / 径違いチーズ=`ラン_枝` / レジューサー=`大径_小径`（値は `{H, od1, od2}`）。

**相手径の自動判定**: レジューサー/径違いチーズの「相手径」は、接続している隣接
セグメントの実効サイズ（自分と径が異なる隣の管）から自動で決まる（`reducerCounterpart`）。
手動選択で上書きも可能（相手径の既定表示が「自動（○A）」）。

#### レジューサーのシンボル描画

- **同心レジューサー**: 二等辺三角形。底辺（広い辺）＝上流（大径）側、頂点＝下流（小径）側。
- **偏心レジューサー**: 直角三角形。斜辺の向きが合わせ面に連動（リアルタイム切替）。
  - 上面合わせ（TOP）: 上辺がまっすぐ・下辺が斜め（斜辺下向き）
  - 下面合わせ（BOTTOM）: 下辺がまっすぐ・上辺が斜め（斜辺上向き）
- 大径側は隣接セグメントのサイズから自動判定し、ルートの向きが変わっても
  常に「上流（大径）＝底辺 / 下流（小径）＝頂点」を維持（`reducerLargeAtStart`）。
- シンボルは配管方向に沿って固定ピクセルで描くため、アイソメ角でも潰れない（縮尺は非厳密）。

#### 偏心レジューサーの芯ズレ

- `reducer_eccentric` 選択時、属性に **相手径** と **合わせ面（上面 TOP / 下面 BOTTOM・必須）** を追加。
- **芯ズレ量 = (大径OD − 小径OD) / 2**（OD は fittings.json の od1/od2）を自動計算し、
  「芯ズレ: ○mm（上面/下面合わせ）」と表示。
- 下流への参考注記「レジューサー基準面から ○mm 上/下に芯がズレています」を表示
  （上面合わせ→芯が下、下面合わせ→芯が上）。図の座標・見た目は変更しない。
- 同心レジューサー（`reducer_concentric`）は芯ズレなしのため非表示。

### マスタデータ（`src/data/`）

- **pipes.json**: 管種（SGP / ステンレス / VP）と呼び径サイズ・外径
- **fittings.json**: 継手種類（エルボ90/45°、チーズ、レジューサー、フランジ、ソケット）と
  サイズ別の中心〜端面寸法（センターマイナス寸法, mm）※値はダミー、後から編集可
- **masters.ts**: 上記 JSON を型付きで読み込むヘルパー

> フェーズ2で「寸法・属性を入力」ポップアップから 管種 / サイズ / 継手（始点側・終点側）を
> 選択でき、セグメントに保存されるようになりました（localStorage 永続化）。
> `fittings.json` の centerToFace はフェーズ3の切断長さ計算で使用します。
